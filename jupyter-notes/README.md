# Jupyter Notes

A focused workspace for Python notebooks, plots, experiments, and written reasoning.

## Layout

- `notebooks/` contains exploratory Jupyter notebooks.
- `src/` contains reusable Python modules.
- `requirements.txt` lists the notebook and plotting dependencies.
- `.venv/` is the local Python environment and is excluded from Git.

## Getting started in VS Code

1. Select the `.venv` Python interpreter when prompted.
2. Open `notebooks/` and create or open a `.ipynb` file.
3. Select the `.venv` kernel in the notebook toolbar.
4. Run cells with `Shift+Enter`.

Git is initialized for this workspace. Review notebook output before committing, and commit focused changes with a short message.
